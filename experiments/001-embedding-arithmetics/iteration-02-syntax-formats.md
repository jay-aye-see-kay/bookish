## Summary

### What changed

- We tested pipe, colon/newline, JSON, INI, YAML, and natural-sentence formats, and subtracted both **bare** markers (`Movie`, `1995`) and **explicit** markers (`category: Movie`, `year: 1995`).
- Explicit markers are *not* embedding-space aliens: `Movie` and `category: Movie` have cosine 0.9053; `1995` and `year: 1995` have cosine 0.8845. Disambiguating the subtrahend therefore does not change the geometry much.

### What stayed the same

- **Subtraction never helped.** For Hackers and Blade Runner it flipped similarities negative and returned random books. For Halo and 1984 it kept some positive signal because those title vectors are very dominant, but scores dropped sharply (e.g. `Book|1984` 0.8848 → subtracted 0.3753 to *Nineteen Eighty-Four*).
- No format made subtraction competitive with the marked input itself.

### Which marked inputs are best

This varies by concept, so the right format is probably **concept-dependent** or we should pick one robust default:

| Concept | Best marked input observed | Why |
|---|---|---|
| Hackers | `The 1995 movie Hackers` | Snow Crash/Neuromancer appear high; avoids computer-security manuals |
| Blade Runner | `Blade Runner (movie)` or `Movie\|Blade Runner` | Strong Philip K. Dick / sci-fi focus |
| Dune | `Movie\|Dune` or raw `Dune` | Keeps the Dune franchise together; `Movie\|2021\|Dune` is more narrowly franchise-focused |
| Halo | `category: Game\ntitle: Halo` | Best separation from the YA novel *Halo* |
| 1984 | `Book\|1984` | Huge boost over bare `1984` (0.8848 vs 0.6985 to *Nineteen Eighty-Four*) |

### Implication

Domain markers are valuable **as part of the input string**, not as removable scaffolding. The embedding model uses them to disambiguate, but it does not encode the input as a sum of independent `marker + title` vectors. Trying to subtract the marker after embedding removes useful signal instead of isolating the title.
